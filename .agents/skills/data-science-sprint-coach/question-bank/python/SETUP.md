# Python and pandas Practice Setup

Use this setup only for the Python and pandas practice track.

1. Open the DataScienceSprintCoach repository in VS Code.
2. Open the integrated terminal at the repository root.
3. Create and activate a local virtual environment if needed:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pandas
```

4. Use the public CSV tables in `resources/sql/` for pandas exercises. Keep joins within the active dataset and validate merge grain.
