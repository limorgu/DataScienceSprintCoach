# ML and Model-Evaluation Question Catalog

- Explain supervised, unsupervised, and self-supervised learning through a role-relevant example.
- Diagnose overfitting and choose an appropriate remedy.
- Design a leakage-safe train, validation, and test split.
- Select a metric for an imbalanced classification problem and defend a threshold trade-off.
- Assess subgroup performance before a launch decision.
- Explain a production metric regression through error analysis and distribution-shift checks.
- Define a target for an escalation-classification problem.
- Calculate precision and recall from a confusion matrix.
- Explain false-positive and false-negative costs.
- Diagnose high recall alongside rising serious complaints.
- Choose a launch decision when aggregate and subgroup metrics conflict.
- Explain oversampling and the production-evaluation distribution.

## Modeling workflow

- Translate a product decision into target, unit of prediction, horizon, and label definition.
- Identify label leakage in a realistic feature set.
- Choose a baseline and explain what it establishes.
- Explain bias-variance trade-offs using model behavior rather than definitions alone.
- Compare L1 and L2 regularization for a sparse feature problem.
- Choose an imputation strategy while preventing training-serving skew.
- Decide when feature scaling matters and when it does not.
- Propose cross-validation for a time-aware dataset without data leakage.

## Evaluation and production

- Read a precision-recall curve and select an operating threshold.
- Explain calibration and design a calibration check.
- Decide whether ROC-AUC or PR-AUC is more informative for a rare event.
- Create a confusion-matrix review for several protected or important segments.
- Design an offline-to-online evaluation plan.
- Diagnose a metric drop after deployment using a prioritized investigation.
- Define data-quality, latency, and outcome monitors for a model service.
- Explain concept drift versus data drift with example symptoms.
- Propose an error-analysis taxonomy and action loop.
- Decide whether to retrain, recalibrate, change the threshold, or pause launch.
