# Privacy boundary

Keep real practice answers, scores, employer or interview details, recordings, transcripts, private links, daily coverage, question status, and next-question state in the local gitignored `private-progress/` folder. The dedicated 9pm progress agent maintains this private record after each practice day.

The public repository contains only topic-organized question catalogs, synthetic schemas, and reusable practice rules. Do not publish personal daily results without explicit approval and full sanitization.
