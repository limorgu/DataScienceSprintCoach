# Four-Week Learning Path

This is the public topic order for the Data Science Sprint Coach. It matches the four-week technical preparation plan. It guides question selection but does not contain any learner progress, scores, or next-question state.

## Week 1 — SQL mastery sprint

SQL is the near-exclusive focus for five practice days: aggregation and CASE, joins (including anti-joins), CTEs/subqueries, window functions, dates, running/business metrics, and Amazon-style schemas. Days 4–5 use one coherent dataset for easy → medium → difficult and timed transfer questions.

After Week 1, SQL moves to maintenance: 1–3 unseen SQL questions per week.

## Week 2 — Python-heavy rebuild

Use roughly 70% Python/pandas and 30% ML/statistics fundamentals, plus SQL maintenance. Prioritize loops, conditions, lists, dictionaries, strings, functions, sliding-window reasoning, time/space complexity, filtering, groupby/aggregation, merges, missing data, calculated columns, and reusable metric functions.

## Week 3 — Python, statistics, experimentation, ML, and evaluation

Continue Python while expanding probability, sampling, confidence intervals, hypothesis testing, power, A/B-test design, classic ML, model selection, class imbalance, thresholds, calibration, and model evaluation.

## Week 4 — mixed interview practice and gap repair

Use mixed interview simulations, targeted ML/statistics review, selected end-to-end data-science cases, and focused repair of remaining gaps. Keep production/system-design reasoning at explanation level unless an interview requires more depth.

## Question-pool behavior

The topic QUESTIONS.md files in the public Resource Library are representative samples. When the skill is installed, it draws a larger, topic-aligned question pool and selects only the next appropriate question for the active week; it does not dump the full pool into a practice session.

A normal week is approximately five practice days. The existing daily workflow, private progress records, 7am training, and 9pm collection remain unchanged. The existing end-of-week 10-question check uses that week's material.
