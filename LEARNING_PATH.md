# Data Science Sprint Learning Path

Use this map to choose one topic. The public library contains only topic metadata and questions; personal coverage, answers, and next choices stay in `private-progress/`.

1. [SQL](resources/library/sql/) — joins, aggregation, CTEs, windows, NULL handling, funnels, and experiments.
2. [Python and pandas](resources/library/python/) — core Python, data structures, pandas, validation, and data quality.
3. [Machine learning](resources/library/ml/) — modeling, evaluation, calibration, monitoring, and production decisions.
4. [Statistics and experimentation](resources/library/statistics/) — probability, inference, A/B tests, causal reasoning, and forecasting.
5. [LLM systems](resources/library/llm/) — retrieval, evaluation, safety, quality, cost, and monitoring.
6. [Design](resources/library/design/) — product flows, research, accessibility, instrumentation, and trade-offs.
7. [Cases](resources/library/case/) — structured data-science and product decisions.
8. [Technical communication](resources/library/communication/) — clear, evidence-based interview communication.
9. [Other](resources/library/other/) — new public-safe topics that do not fit the core tracks.
