# Technical Communication Question Catalog

- Give a structured technical explanation for a non-technical interviewer.
- Answer a behavioral question with situation, action, outcome, and reflection.
- Explain a trade-off and invite an interviewer to test the reasoning.
- Respond to a follow-up that challenges an assumption without becoming defensive.

## Interview communication

- Open a technical answer with a one-sentence recommendation.
- Ask clarifying questions before solving an ambiguous prompt.
- Narrate a SQL or Python solution while preserving precision.
- Explain an evaluation metric to a product manager.
- State an uncertainty and propose the evidence needed to resolve it.
- Recover gracefully after noticing an error in an answer.
- Summarize a complex analysis in 60 seconds and in three minutes.
- Explain a disagreement with a stakeholder using evidence and trade-offs.
- Answer a question about a project while protecting confidential details.
- Close an interview answer with a check for alignment.
