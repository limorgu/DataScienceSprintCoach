# Design Question Catalog

- Clarify an ambiguous user problem before proposing a solution.
- Map an end-to-end flow with success and failure states.
- Prioritize needs, constraints, and trade-offs for a constrained surface.
- Define success metrics and qualitative research signals.
- Explain how accessibility and edge cases affect a design decision.

## Product and systems design

- Turn a vague request into a problem statement and measurable user outcome.
- Sketch an information architecture for a data-heavy workflow.
- Identify the riskiest assumption and design the fastest learning test.
- Decide what belongs in an MVP versus a later iteration.
- Design states for empty, loading, error, and permission-denied conditions.
- Balance discoverability, cognitive load, and power-user efficiency.
- Write a research plan for an uncertain workflow.
- Reconcile conflicting feedback from different user segments.
- Explain a design decision to engineering with implementation constraints.
- Define an instrumentation plan for a new feature.
