# Topic Resource Library

Follow the [four-week learning path](../../LEARNING_PATH.md), then choose the current week's topic folder below. Each topic contains exactly:

- `ENVIRONMENT.md` — tools, data type (SQLite/CSV/DataFrame or conceptual), approved public resources, and covered competencies.
- `QUESTIONS.md` — representative public sample questions for that topic.

The installed skill uses the larger topic-aligned question pool and presents only the next question appropriate for the active week. Do not store answers, coverage status, scores, or next-question selection here.
