# LLM Question Catalog

- Define users, task, and failure costs for an LLM-assisted workflow.
- Propose a synthetic, privacy-safe evaluation set and its limits.
- Choose quality, safety, latency, and cost metrics with trade-offs.
- Diagnose prompt, retrieval, model, and policy failure modes.
- Design a human-review boundary and monitoring plan.

## Evaluation and system design

- Define a rubric for groundedness, helpfulness, and safety.
- Compare pointwise scoring, pairwise preference, and task success evaluation.
- Design a retrieval evaluation that separates recall from answer quality.
- Investigate an unsupported-answer failure with an evidence trace.
- Choose between prompt revision, retrieval change, fine-tuning, and policy guardrails.
- Design a red-team plan for sensitive or high-impact use.
- Specify a fallback behavior when confidence or retrieval quality is low.
- Define an annotation guide and measure annotator agreement.
- Analyze latency, quality, and cost trade-offs for a multi-step agent.
- Propose monitoring for prompt drift and changing user behavior.
